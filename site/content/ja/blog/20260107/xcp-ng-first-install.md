アップストリームの XCP-ng 8.3 を初めてインストールする著者の手順を、インストーラー ISO から Xen Orchestra アプライアンスのデプロイまで、アップストリームのインストーラーの写真とともに紹介します。
{class="lead"}

{{< callout type="warning" >}}
この手順は **アップストリームの XCP-ng 8.3** を対象としており、XCP-hl ではありません。XCP-hl は XCP-ng 8.3 を基盤とするアルファ版ソフトウェアであるため、インストーラーの表示や一部の既定値は XCP-hl では異なる場合があります。以下の写真はアップストリーム 8.3 のインストーラーを示しています。
{{< /callout >}}

## このページについて

これは著者による XCP-ng 8.3 初回インストール手順で、2026-01-07 に著者の個人ブログで公開され、[PR #409](https://github.com/Vagrantin/xcp-hl/pull/409) に記録された 2026-11-11 のオーナー決定に基づき、このサイトに移管されました。[はじめに](/docs/start/) のページが実稼働ドメインでこのページにリンクできるようにするためです。XCP-hl の手順（ISO のダウンロード、チェックサム検証、XOA-hl アプライアンス）については、[はじめに](/docs/start/) を参照してください。

## 始める前に

- XCP-ng 8.3 でサポートされる専用マシン。ハードウェア仮想化を有効にしてください。[アップストリームの要件](https://docs.xcp-ng.org/installation/requirements/)を参照。
- 使用するディスク上のデータはバックアップしてください。**インストールは選択したディスクを消去します。**
- インストール用ディスクに最低 100 GB、さらに VM 用の空き容量。
- 管理用の安定した IP アドレス、ゲートウェイ、DNS、NTP の設定。静的アドレスまたは DHCP 予約にするとホストを見つけやすくなります。
- ホストへのネットワークアクセスとブラウザーを備えた 2 台目のコンピューター。

## ISO を USB メモリに書き込む

[アップストリームのダウンロードページ](https://xcp-ng.org/download/)から XCP-ng 8.3 の ISO をダウンロードし、USB メモリに書き込みます。書き込みによって USB メモリは消去されるため、まず `dmesg` で USB メモリがどのデバイスかを確認し、以下の `sdX` をそのデバイス名に置き換えてください。

```bash
sudo dd if=xcp-ng-8.3.0-20250606.iso of=/dev/sdX bs=8M oflag=direct
```

コマンドを実行する前にデバイス名を必ず再確認してください。誤ったディスクに書き込むとそのディスクが消去されます。コピーが完了するまで待ちます。USB メモリの性能によっては時間がかかることがあります。

## XCP-ng をインストールする

XCP-ng はタイプ 1 ハイパーバイザーであり、マシンに単独でインストールすることを前提としています。USB メモリを接続してそこからブートし、ブートプロンプトで Enter を押します。

1. **キーボードレイアウトを選択**し、続行する前にインストールの警告とライセンス契約をお読みください。

   {{< screenshot src="install/keyboard.jpg" alt="インストーラーのキーボードレイアウト選択" >}}

2. **システムディスクと VM 保存用ディスクを選択します。** デバイス名と容量を確認してください。インストール用 USB メモリや、データを保持したいディスクは選択しないでください。

   {{< screenshot src="install/system-disk.jpg" alt="システムディスクの選択" >}}
   {{< screenshot src="install/vm-disk.jpg" alt="仮想マシン保存用ディスクの選択" >}}

3. **ストレージタイプを選択します。** EXT（シンプロビジョニング）は実際に使用している容量だけを消費します。例えば 1 TB の仮想ディスクに 20 GB のデータがあれば、ホスト上では約 20 GB しか使いません。その代わり、データが増えるたびにディスクファイルが拡張されます。LVM（シックプロビジョニング）は作成時に全容量を確保し、その拡張を避けますが、その分の容量を消費します。ホームラボでは EXT が実用的な既定値です。パフォーマンスが重要なワークロードには LVM が適しています。ディスクは後から Xen Orchestra で拡張できます。

   {{< screenshot src="install/storage-type.jpg" alt="EXT と LVM のストレージ選択" >}}

4. **インストール元には Local media を選択**し、メディアの検証が提供されたら実行してください。ダウンロードや USB メモリの破損が疑われる場合は特に実行をお勧めします。

   {{< screenshot src="install/source.jpg" alt="インストール元として Local media を選択" >}}

5. **root パスワードを設定して控えます。** このパスワードはプラットフォームで最も重要なものなので、安全な場所に保管してください。XO Lite へのサインインと、ホストを Xen Orchestra に接続するときに使用します。

   {{< screenshot src="install/password.jpg" alt="ホストの root パスワードの設定" >}}

6. **管理ネットワークと DNS を設定します。** 静的アドレスまたは DHCP 予約を使用してください。VLAN はネットワークで必要な場合にのみ使用します。ホスト名と到達可能な DNS サーバーを入力します。後でアドレスが変わった場合、ラボ内に DNS がないとホストを見つけられなくなります。

   {{< screenshot src="install/network.jpg" alt="管理 IP アドレスとゲートウェイの設定" >}}
   {{< screenshot src="install/dns.jpg" alt="ホスト名と DNS サーバーの設定" >}}

7. **タイムゾーンと NTP サーバーを設定し、インストール内容を確認します。** ホストがインターネットに接続できる場合は公共 NTP サーバーを、接続できない場合は内部 NTP サーバーを使用してください。インストールを開始する前に、選択したディスクを確認します。

   {{< screenshot src="install/ntp.jpg" alt="時刻同期の設定" >}}
   {{< screenshot src="install/confirm.jpg" alt="インストールの最終確認" >}}

8. **完了し、インストールメディアを取り外して再起動します。** ホストコンソールに表示される管理アドレスを控えてください。

   {{< screenshot src="install/complete.jpg" alt="インストール完了、再起動の準備完了" >}}

## 初回ブート後: XO Lite

ホストコンソールでは、このホスト単体の基本的な管理（ネットワーク、VM、リソース、バックアップとリストア）が行えます。単一ホストを管理するもう 1 つの方法が XO Lite です。ホストが既定の HTTPS ポートで提供する Web インターフェースで、ブラウザーで `https://<ホストの IP>`（または `https://<ホスト名>`）を開きます。ホストは最初自己署名証明書を使用します。証明書を受け入れる前に、自分のホストに接続していることを確認してください。インストール時に設定したパスワードで `root` としてサインインします。

## XOA をデプロイする

XOA（Xen Orchestra）は、1 つ以上の XCP-ng ホストとその VM を管理する Web アプリケーションです。ホスト上で仮想マシンとして実行されます。

1. XO Lite で **Deploy XOA** をクリックし、アプライアンスイメージを選択します。XCP-hl では既定の選択肢は **XOA-hl** です。[はじめに](/docs/start/)を参照してください。
2. フォームに表示されるネットワークとデプロイの項目を入力し、選択したイメージと認証情報を確認して、**Deploy** をクリックします。
3. アプライアンス VM が起動するのを待ち、そのアドレスをブラウザーで開いてサインインします。アプライアンスにはホストの XO Lite アドレスとは別の専用アドレスがあります。

Xen Orchestra でホストを接続したら（`Settings → Servers → Add server` でホストのアドレスと root 認証情報を入力）、インストール用 ISO を ISO ライブラリにアップロードし、最初の VM を作成します。[アップストリームのインストールガイド](https://docs.xcp-ng.org/installation/install-xcp-ng/)にはさらに詳しいオプションが記載されています。
