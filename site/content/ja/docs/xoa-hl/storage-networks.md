**XOA-HL アプライアンス**の管理者として、停止中の使い捨て VM で練習します。VM の識別情報、既存のディスクとインターフェースを記録します。十分な空き容量を持つ書き込み可能な SR と、XO の外部で隔離を確認した既存のネットワークを選びます。アプライアンス自体をテスト用ゲストにしないでください。

{{< callout type="info" >}}
イメージ `xoa-image-20261009-5f33c81`、パッケージ `v5.113.2_e281c536-ce38`、XO 5.113.2 を対象としたソース確認済みのプレビューです。配布されたアプライアンスでのディスク、インターフェース、ゲスト内の認識テストは未完了です。
{{< /callout >}}

## 1. オブジェクトを識別する

| オブジェクト | 意味 |
| --- | --- |
| SR | 仮想ディスクを保存するストレージリポジトリ。空き容量を確認する |
| VDI | SR に保存された仮想ディスクのデータ |
| VBD | VM と仮想ディスクの接続 |
| VIF | VM の仮想ネットワークインターフェース |
| PIF | ホストのネットワークインターフェース。管理接続を変更するとホストとの接続を失う場合がある |

VM のインターフェースとホストの管理インターフェースは別です。ネットワークの選択や MAC の生成だけでは隔離できません。クローンや復元したゲストに使う前に、実際の VLAN、物理接続、ルーティングを確認します。

## 2. 小さな空のディスクを追加する

1. テスト VM の停止を確認します。**Disks** (`/#/vms/<id>/disks`) を開き、**New disk** を選びます。
2. 同じプール内の対象の書き込み可能な SR、明確なテスト名、単位を指定した小さなサイズを選びます。書き込み用のテストディスクでは読み取り専用を無効にします。作成を一度だけ実行し、完了を待ちます。
3. 新しい行で名前、サイズ、SR、対象 VM への接続を確認します。ディスクの識別情報と SR の空き容量を記録してからゲストを起動します。

ゲストのコンソールで、サイズとデバイス情報を使って新しいディスクを識別します。XO は仮想ディスクと接続を作成しますが、ゲスト内のパーティション作成、フォーマット、マウントは自動で行いません。ゲストのファイルシステム操作はこの検証の対象外です。推測したデバイス名だけを根拠にフォーマットしないでください。

作成に失敗したら、再試行前にタスクと VM/SR の一覧を確認します。途中まで完了した操作でディスクが残る場合があります。エラーを保存し、容量と接続を調べ、必要なら[トラブルシューティング](/docs/xoa-hl/troubleshooting/)を参照します。この練習ではディスクの縮小、拡張、ストレージ移行を検証しません。

## 3. 取り外しと削除を区別する

VBD の削除は VM からディスクを取り外します。VDI のデータを削除したことにはなりません。VDI の削除はディスクデータを破壊する別の操作で、この画面では接続中は利用できません。接続を切断する操作も、接続自体の削除とは異なります。

片付けるときはゲストを停止し、空のテストディスクだけを確実に識別します。内容が必要になる可能性があれば VDI を残してください。容量警告を解消するために起動ディスク、共有ディスク、識別できない VDI を削除しないでください。[重要なゲストデータは別にバックアップ](/docs/xoa-hl/backup-restore/)します。

## 4. 隔離した VM インターフェースを追加する

停止中のテスト VM で **Network** (`/#/vms/<id>/network`) を開き、**New device** を選びます。同じプール内の隔離を確認したネットワークを指定します。MAC 欄を空にして自動生成を使い、**Create** を選びます。起動前にインターフェース、ネットワーク、MAC を確認し、起動後にゲストの認識と予定した接続を確認します。

クローンや復元を隔離するときは、停止中に継承した VIF を**すべて削除**し、初回起動前に一覧が空であることを確認します。接続切り替えだけではなく、インターフェースの削除を使います。単なる切断はこの隔離手順ではありません。本番に到達しないことを確認し、コピーされた識別情報を解消してからテスト用ネットワークを追加します。

想定外の接続があれば、テスト VM を停止し、再試行前に接続先と外部の隔離を確認します。このガイドではホストの PIF、管理アドレス、ボンド、VLAN を設定しません。練習中にホストの管理ネットワークを変更しないでください。[VM 操作](/docs/xoa-hl/vm-operations/)または[ホストとプールの管理](/docs/xoa-hl/hosts-pools/)に進めます。
