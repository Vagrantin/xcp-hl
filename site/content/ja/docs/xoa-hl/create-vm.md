小さなテスト用 VM を作成して OS をインストールし、その VM 自身の仮想ディスクから起動することを確認します。

{{< callout type="info" >}}
**対象:** イメージ `xoa-image-20261022-a280852`（Xen Orchestra 5.113.2）。公開済みのコードに基づく手順で、検証環境での通しの確認とゲスト OS ごとのテストはまだです。以下のサイズは例であり、対応 OS の一覧ではありません。
{{< /callout >}}

## 始める前に

- [ログインしてホストを接続します](/docs/xoa-hl/first-login/)。このガイドでは XOA-HL の管理者アカウントを使います。
- OS の提供元からインストール用 ISO をダウンロードします。提供元が公開しているチェックサムで確認します。
- 2 種類のストレージを確認します。インストールメディア用の **ISO SR** と、VM ディスク用に空きのある **書き込み可能な SR** です。[XCP-HL の ISO ライブラリ](/docs/features/#iso-storage)は、すべてのホストにあるわけではありません。
- VM ディスク用に新しい SR が必要な場合は、先に[空の専用エクスポートで NFS ストレージを作成](/docs/xoa-hl/storage-networks/#nfs-vm-storage)します。この VM のインストールが済んだら、そのページのディスクの確認に戻ります。
- インストーラーに必要な通信ができるゲストネットワークを選びます。XOA-HL と他の VM のために、ホストのメモリとストレージに余裕を残します。

VM の管理は **ブラウザー** で行います。OS のインストールは **新しい VM のコンソール** で行います。XCP-HL ホストや XOA-HL アプライアンス上では行いません。

## 1. インストール用 ISO を用意する

確認済みのインストーラーが ISO ライブラリに既にある場合は、それを使ってこの手順を飛ばします。専用の NFS ライブラリを接続する場合は、[NFS の ISO ライブラリを接続する](/docs/xoa-hl/storage-networks/#nfs-iso-library)に従います。

ブラウザーからのアップロードは、ISO SR が新しいファイルを受け付け、十分な空きがある場合にだけ使えます。インポート先の一覧に SR が表示されても、それは保証されません。メディアの読み取りだけでアップロードを受け付けないライブラリもあります。

1. **インポート → Disk**（`/#/import/disk`）を開きます。ダウンロードしたファイルをアップロードするため、**From URL** はオフのままにします。
2. **ISO SR** を選びます。たとえば `XCP-HL ISO library` があればそれを選びます。アップロード領域に `.iso` ファイルをドロップします。
3. ファイル名と保存先を確認します。**インポート** を選び、完了するまで待ちます。
4. 保存先 SR のディスク一覧を開き、ISO があることを確認します。アップロードが終わっていない状態で先に進まないでください。

適切な ISO SR が表示されない場合は、先に用意します。通常の VM ディスク用ストレージに ISO を取り込んでも、ISO ライブラリにはなりません。

## 2. VM を作成する

**新規作成 → 仮想マシン(VM)**（`/#/vms/new`）を開き、**プール** を選びます。OS がインストール済みのテンプレートではなく、OS をインストールするためのテンプレートを選びます。

VM には `lab-first-vm` など分かりやすい名前を付けます。次のサイズは、提供元の要件を満たす場合、小さな Linux のテスト環境に使えます。

| ウィザードの項目 | 選ぶもの |
| --- | --- |
| 仮想マシン(VM)情報 | インストール用テンプレート、名前、説明。 |
| スペック | 例：2 vCPU、2 GiB の RAM。インストーラーがより多く必要とする場合は増やします。 |
| インストール設定 | **ISO/DVD** を選び、インストール用 ISO を選びます。 |
| ネットワークインタフェイス | ゲストネットワーク。ネットワークで固定の MAC アドレスが必要な場合を除き、空欄にして自動生成させます。 |
| 仮想ディスク | 例：ホストから使える書き込み可能な SR に 20 GiB のディスクを 1 つ。システムディスクを ISO SR に置かないでください。 |
| 詳細設定 | ゲストに必要な変更がない限り、テンプレートの既定値のままにします。自分で起動するため、**Boot VM after creation** のチェックを外します。 |
| 概要 | プール、テンプレート、CPU、メモリ、ネットワーク、ストレージを確認します。 |

**VMの作成** を選びます。

**確認:** 指定した名前の VM が 1 台表示され、設定が選んだ内容と一致します。**VMの作成** が押せない場合は、必須項目かリソースの確認が終わっていません。ウィザードを見直してから再試行します。

コンソールの操作や、画面が真っ暗・固まった場合は、[VM のコンソールを使う](/docs/xoa-hl/vm-operations/#vm-console)を参照してください。

## 3. OS をインストールする

1. 新しい VM を開き、名前を確認します。VM を起動し、**コンソール** タブを開きます。
2. インストーラーが起動することを確認します。このゲスト内で、提供元のインストール手順に従います。
3. インストール先のディスクを聞かれたら、**新しい VM の仮想ディスク**（この例では 20 GiB）であることを確認します。ディスクに既にデータがある場合は中止し、正しい VM を選んでいるか確認します。
4. インストールが終わったら、VM の **Disks** タブを開き、仮想 CD ドライブから ISO を取り出します。ゲストを通常の方法で再起動し、仮想ディスクから起動することを確認します。

{{< callout type="warning" >}}
操作するのは新しいテスト用 VM だけにしてください。ディスクのフォーマットや強制シャットダウンでは、データが失われることがあります。ゲストが応答する場合は、通常のシャットダウンや再起動を使います。ゲスト 1 台を再起動するために、XOA-HL アプライアンスやホストを停止しないでください。
{{< /callout >}}

## 4. 結果を確認する

- インストール用 ISO なしでゲストが起動し、コンソールからログインできます。
- VM の CPU、メモリ、ディスク、ネットワークが選んだ内容と一致します。
- ゲスト内で、IP アドレス、ゲートウェイ、DNS、必要な通信が使えます。ゲストのネットワークが使えない場合も、コンソールは使えます。
- ゲスト OS のバージョン、テンプレート、VM 名、XOA-HL のバージョンを控えています。

ゲストツールは OS によって異なります。Ubuntu 24.04 の場合は、下の「次の手順」を参照してください。

この VM には、まだ独立したバックアップがありません。同じストレージ上のスナップショットでは、そのストレージが失われたときに守れません。バックアップと復元を試すまで、この VM に重要なデータを置かないでください。

## うまくいかない場合

| 症状 | 確認すること |
| --- | --- |
| ウィザードに ISO が表示されない | ISO SR へのアップロードが完了しているか、選んだプールやホストからその SR を使えるかを確認します。 |
| **VMの作成** が押せない | プール、テンプレート、名前、リソース、ISO、ネットワーク、ディスクのストレージを確認します。必須項目をすべて入力します。 |
| VM の作成や起動に失敗する | タスクのエラーを読みます。ホストの空きメモリ、SR の空き容量、ホストから選んだストレージとネットワークを使えるかを確認します。再試行の前に、VM が既に作成されていないか確認します。 |
| 再起動のたびにインストーラーが起動する | この VM の CD ドライブから ISO を取り出します。OS が仮想ディスクにインストールされたか確認します。 |
| ゲストのネットワークが使えない | 選んだネットワークと、ゲストの IP アドレス、ゲートウェイ、DNS を確認します。ゲストの問題を直すために、ホストの管理ネットワークを変更しないでください。 |

## 次の手順

1. [テスト用 VM をバックアップし、復元を確認する](/docs/xoa-hl/backup-restore/)。
2. Ubuntu 24.04（amd64）のゲストでは、[管理エージェントをインストール](/docs/xoa-hl/guest-tools/#install-linux-agent)します。他の OS には、それぞれの手順が必要です。
3. インストール済みのゲストを再利用するには、[テンプレートから新しい VM を作成](/docs/xoa-hl/templates/#deploy-template)します。

[用語集](/docs/xoa-hl/glossary/)と[アップデートガイド](/docs/guides/updates/)も参照してください。
